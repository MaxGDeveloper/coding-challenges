# AGENTS.md — coding-challenges

## Что это

Банк тестовых и учебных заданий в Markdown. Кода приложения, `package.json`, сборки, тестов,
линтеров и CI в репозитории нет — запускать `npm install`/`npm run build` нечего. Задания
выполняются в отдельных проектах, а не внутри этого репозитория.

## Правила правок

- `tasks/*.md` — публичные ТЗ для кандидатов и студентов. Любая правка меняет условие задания:
  не переформулируй требования и не «улучшай» формулировки без явной просьбы.
- Язык документов — русский, кодировка UTF-8 без BOM, в рабочей копии CRLF
  (`core.autocrlf=true`, в индексе LF). Сохраняй это при правках.
- Новое задание — `tasks/<kebab-case>.md` в том же формате, что и существующие
  (стек → описание/этапы → критерии приёмки).
- `README.md` — единственная точка входа и оглавление: после добавления или переименования
  файла в `tasks/` обнови список ссылок.
- Правила веток и Pull Request из `tasks/vue-team-git-ci.md` относятся к учебному проекту
  студентов, а не к этому репозиторию.

## Задания

- `tasks/weather-quest.md` — индивидуальное: Vue 3 + Vite + PrimeVue, Open-Meteo API.
- `tasks/vue-team-git-ci.md` — групповое: Vue 3, Git, GitHub Actions, GitHub Pages.
