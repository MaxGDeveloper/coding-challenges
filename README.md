# coding-challenges

Тестовые и учебные задания для кандидатов на позицию программиста и для учебных групп.
Основной стек — Vue 3 (Composition API) + TypeScript.

В репозитории только условия заданий: готового приложения, зависимостей и сборки здесь нет.
Каждое задание выполняется в отдельном проекте.

## Задания

- [Прогноз погоды](tasks/weather-quest.md) — индивидуальное тестовое задание: SPA на Vue 3,
  Vite, PrimeVue и Open-Meteo с маршрутизацией и обработкой ошибок. Ориентировочно 1–2 дня.
- [Командный сайт на Vue 3 + Git + GitHub Actions + GitHub Pages](tasks/vue-team-git-ci.md) —
  групповое задание: общий сайт с карточками участников, работа через ветки и Pull Request,
  CI и деплой на GitHub Pages.

## Как пользоваться

Откройте нужное задание и следуйте его требованиям и критериям приёмки. Для выполнения
создаётся отдельный проект — этот репозиторий содержит только условия.
